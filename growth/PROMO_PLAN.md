# 홍보 실행 계획 — 한국 시장 플레이북 (솔로 개발, 주 5~10h)

> 파티게임의 성장 공식(어몽어스·구스구스덕 한국 사례): 마케팅비가 아니라
> **"방송에서 웃긴 그림이 나오는 게임" + 스트리머 시청자 참여 합방**이 엔진.
> 구스구스덕: 무명 → 2021-12-25 강소연 합방 1방 → 동접 수십→수천 → 어몽어스 추월.
> 카우보이 파티의 "방 코드 즉석 입장"은 시청자 참여 방송 포맷과 정확히 일치 —
> 섭외 피치는 "게임 소개"가 아니라 **"시청자랑 바로 할 수 있는 방송 콘텐츠 하나 드립니다"**로.

## 1. 스토어 에셋 스펙 (Claude가 제작할 것)

| 에셋 | 스펙 | 상태 |
|---|---|---|
| 아이콘 | 512×512 PNG ≤1MB | 있음(A/B용 2안 추가 제작 예정) |
| 피처 그래픽 | **1024×500** JPEG/24-bit PNG(알파 불가) — 프로모 영상 썸네일 역할, 영상 노출에 필수 | 있음(리뉴얼 예정) |
| 스크린샷 | 2~8장, 한 변 320~3840px. 세로 1080×1920 + **가로 16:9 3장 이상**(게임탭 추천 노출 자격) | 재촬영 예정 |
| 프로모 영상 | YouTube 개별 URL, 공개/미등록, **수익창출 OFF**, 첫 30초 승부 | 미제작 |

- 스크린샷 첫 3장이 전부(유저 ~90%가 3장 이후 안 봄): ①가치 약속("친구 4명, 방 코드 하나, 즉석 결투") ②핵심 플레이 ③재미 증거. 캡션 3~5단어.
- 게임은 실제 인게임 화면 필수(연출컷만 쓰면 정책 위반 소지).
- 오픈 후 트래픽 쌓이면 **Play Console 내장 A/B(무료)** 아이콘 실험이 가성비 1순위.
- 사전등록: 무명 인디 단독 효과 제한적 — 켜두기만 하고 시간 투자 안 함.

## 3. 4주 실행 캘린더 (공개 전환 기준 — 시점은 사용자 결정)

- **W1 오픈 준비(~8h)**: 리스팅 완성(키워드 제목·짧은설명), 스크린샷 8장(가로 3장 포함), 피처 그래픽, 아이콘 2안, 30초 영상 1개 유튜브 업로드, 비공개 테스터에게 리뷰·별점 요청(오픈 직후 별점 방어), 디스코드/X 계정 개설+티저.
- **W2 런칭 주간(~10h)**: 프로덕션 전환 → D0 디시 선물코드 이벤트 글+출시 트윗 → D1~3 네이버 카페·루리웹·디스이즈게임 제보 → 첫 숏폼 2개 → "오픈 기념 결투의 밤"(개발자 상주 = 초기엔 사람이 곧 콘텐츠).
- **W3 스트리머+숏폼(~7h)**: 스트리머 10~15명 리스트업, 메일 5통/주, 숏폼 주 2~3개 유지, 반응 좋았던 커뮤니티 후속 글, 지표 확인(전환율·방 생성률·초대 경유 설치).
- **W4 실험+정착(~6h)**: 아이콘 A/B 시작, 정기 결투전 요일 고정, 스트리머 2차 발송+응답자 지원(전용 코드·방), 회고 → 상위 2채널 집중.

## 4. 바이럴 루프 체크 (게임 내 — RETENTION_PLAN과 연동)
- K-factor = 초대 수 × 전환율, 캐주얼 현실 목표 0.2~0.4. 솔로 게임에선 **초대 루프가 유일한 복리 성장원**.
- ①방 생성 직후 카톡 공유 1탭 ②WOW 모먼트 직후 자랑하기(기구현 — 정확한 원칙) ③"친구 3명 초대 진행바+보상" ④신규가 빨리 초대자가 되게.
