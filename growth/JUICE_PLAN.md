# 타격감(Juice) 고도화 계획 — 하스스톤 방법론 기반

> 리서치 출처: GDC "Hearthstone: How to Create an Immersive UI" · Blizzard 사운드팀 인터뷰 ·
> "Juice it or lose it"(Jonasson&Purho) · "The Art of Screenshake"(Vlambeer) · Game Feel(Swink).
> 현재 상태: `widgets/juice.dart`(화면흔들림+붉은 비네트+햅틱)만 있음 — 사용자 평가 "단순 화면 흔들림 수준" 정확함.

## 핵심 원리 (하스스톤이 만족스러운 이유)

1. **사운드가 경험의 절반** — 침묵하는 인터랙션이 없다. 모든 버튼·이동·타격에 소리. 우리는 SFX 12개뿐, 변형·피치랜덤 없음 → **최대 격차가 여기**.
2. **작은 폴리시 30개의 누적** — 큰 효과 1개가 아니라 머즐플래시+반동+넉백+플래시+파티클+히트스톱이 겹쳐야 "박힌다".
3. **주스 = 정보 전달** — 흔들림 강도가 데미지를, 소리 위계가 사건 크기를 알려준다(장식 아님).
4. **일관된 모션 언어** — 모든 UI 등장은 easeOutBack "슬램", 모든 버튼은 눌림+소리.
5. **의식(Ceremony)** — 결투 예열(정적→폭발), 승리 셀레브레이션. 서부극 클리셰(노을·바람·정적)가 곧 주스.

## 구현 3단계 (각 단계 = 1커밋·에뮬 검증 단위)

### 1단계 — 총격의 심장 ✅ 완료 (2026-07-12, 에뮬 검증)
> 구현: gunshot_a/b/c.wav(사용자 승인 "크랙+펀치" 레이어드) + `audio/juice_sfx.dart`(soloud, 피치±8%·직전회피 풀) ·
> `widgets/hit_burst.dart`(자작 파티클 — newton과 비교 후 사용자 선택) · `widgets/seat_motion.dart`(반동 8px+2°/넉백 12px/흰 플래시 80ms, 아케이드 과장 승인) ·
> 히트스톱(juice.dart timeDilation, 명중 50ms·내 피격/사망 80ms) · 머즐 섬광 70ms(effects.dart) · 흔들림 미세 회전.
> ⚠️ **사운드 도입 규칙(사용자 지시): 새 SFX/음악은 반드시 시청 보드로 사용자가 직접 듣고 승인 후 채택** — jsfxr 단독 품질이 기준 미달이었음.
| 요소 | 구현 |
|---|---|
| 발사음 3종 변형 + 피치 ±8% 랜덤 | jsfxr로 생성, `flutter_soloud` 도입(저지연·피치 지원, Flutter 공식 쿡북 권장) |
| 머즐 플래시 | 총구 위치 60ms 섬광 위젯 |
| 총 반동(kickback) | 발사자 4~8px 반대방향 밀림 → easeOut 복귀 |
| 피격 흰색 플래시 | ColorFiltered 80ms |
| 넉백 | 피격자 탄 방향 임펄스 |
| 명중 파티클 | CustomPainter 파티클 시스템 1개 자작(원 8~15개+중력, RepaintBoundary) 또는 `newton_particles` |
| 히트스톱 | 명중 순간 40~80ms 로컬 연출 정지(시뮬레이션은 유지 — 온라인 동기화 불변) |
| 화면흔들림에 미세 회전 추가 | 기존 juice.dart Transform에 rotate 성분(JW Nijman 팁) |

### 2단계 — 사운드 정체성 + 의식 (예상 2~3일)
| 요소 | 구현 |
|---|---|
| SFX 25~30개 체계 | 총격5·타격6·캐릭터3·UI5·연출4·앰비언스2 (SOUND_GUIDE.md 갱신) |
| 결투 예열 연출 | 쇼다운 직전 0.8~1.5s: 음악 정지+바람 SFX+줌인+"DRAW!" 슬램 |
| 승리 셀레브레이션 | 금색 파티클+배너 슬램+팡파레+heavy 햅틱 — 자랑하기 버튼과 연결 |
| 음악 4상태 | 로비 루프 / 긴장(음악 끄고 바람) / 쇼다운 트랙 / 승·패 스팅 5~8초. 크로스페이드 0.5~1s |
| 버튼 공통 위젯 | 모든 버튼 scale 0.95 눌림+탭음 (전 화면 일괄 교체) |
| 햅틱 계층화 정리 | 발사 light / 피격 medium / 사망·승리 heavy. 연사 시 스로틀 |

### 3단계 — 생명감·영속성 (반응 보고, 예상 2일)
숫자 팝(데미지) · 킬 슬로모(쇼다운 마지막 킬 0.3~0.5s) · idle 애니(숨쉬기·회전초) ·
탄피/탄흔 영속(CustomPainter 1장, 상한 50) · 사망 연출(모자 굴러감) · 로비 소품 인터랙션(선인장·술병 탭) · 관중 환호.

## 성능 수칙
- 파티클·트레일·탄피는 위젯 늘리지 말고 **CustomPainter 한 캔버스** + RepaintBoundary.
- 흔들림은 최상위 래퍼 한 곳(기존 JuiceLayer 유지·확장).
- 검증은 `--profile` 모드 + 에뮬 실플레이 스크린샷.

## 사운드 반복 회피 표준 (전 SFX 공통)
- 자주 나는 소리(발사·피격)는 3~5종 풀에서 직전과 다른 것 랜덤.
- 재생마다 피치 ±5~10%, 볼륨 ±10%.
- ※ 이 수치는 업계 표준 관행(하스스톤 공식 수치 아님).

## 기술 의존성
- `flutter_soloud`(pub) — audioplayers는 SFX 지연 체감, 피치 제어 약함. 도입 시 기존 재생 경로 이전 필요.
- `newton_particles`(pub, MIT) 또는 자작 CustomPainter — 외부 연결 불필요.
- 신규 SFX 생성: jsfxr(무료 CLI) + Kenney CC0 + (선택) ElevenLabs — TOOLS_SETUP.md 참고.
