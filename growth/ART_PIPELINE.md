# 아트 리소스 "AI 외주" 파이프라인 — 설계 (2026-07-12 사용자 요청)

> 사용자 질문: "GPT로 Godot 엔진에 넣을 아트 리소스를 만든다는데, 이 방법을 설계하고 자동으로
> 개입해서 리소스를 만들 수 있나? 직접 만들기보다 외주가 좋아 보인다."
> **답: 가능하고, 이미 그 방향으로 설계돼 있다.** Godot 사례의 본질은 엔진이 아니라
> "AI API가 에셋을 생산(외주) + 도구가 자동으로 엔진에 배치"이며, 우리는 Flutter라서
> 배치·검증까지 Claude가 코드로 직접 한다. Godot MCP 같은 엔진 연동은 우리에겐 불필요.

## 파이프라인 5단계 (전 단계 Claude 자동, 사용자는 품질 승인만)

```
① 스타일 가이드 → ② 생성(외주) → ③ 후처리 → ④ 배치 → ⑤ 검증
```

1. **스타일 가이드 고정** (1회): 기존 `assets/characters` PNG에서 팔레트·선 굵기·비율을 추출해
   프롬프트 템플릿 1장으로 고정 (PRODUCT_PLAN 백로그 5번과 동일 작업). 이게 없으면 생성물이 제각각.
2. **생성 = 외주**: API에 "참조 이미지(기존 캐릭터) + 스타일 템플릿 + 변형 지시"를 보내 후보 4~8장 생성.
   - 기본: **Gemini(연결 완료, 무료 500장/일)** — 이미지 편집(참조 기반 변형)에 강해 스킨·표정 변형에 적합
   - 선택: **GPT(gpt-image-1)** — 지시 이행·일관성 우수, OpenAI 키 필요($0.01~0.19/장). Gemini 품질이 아쉬울 때
   - 선택: **Recraft** — Style ID로 세트 전체 스타일 고정, 스킨 12종 같은 "시리즈 생산"에 최적(~$0.04/장)
3. **후처리 자동화**: `rembg`(배경 제거 — bintage에서 이미 검증된 도구) → ImageMagick 트림·리사이즈·
   규격 통일(캐릭터 512px 등) → 필요 시 스프라이트 시트 합성.
4. **배치**: `assets/characters|sounds|...`에 규격명으로 저장 + pubspec/코드 배선 — Claude가 직접.
5. **검증**: 에뮬레이터 실행 스크린샷으로 인게임 확인 → 후보 중 최종안만 사용자에게 골라달라고 제시.

## 운영 방식
- Claude가 배치(batch)로 돌린다: "스킨 12종" 같은 주문 → 캐릭터당 후보 4장 생성 → 후처리 →
  인게임 합성 스크린샷 시트 1장으로 보고 → 사용자는 O/X만.
- 스크립트는 `tools/gen_art.sh`(생성+후처리 일괄)로 만들어 재사용 — 첫 스킨 작업 때 함께 구현.

## 사용자 결정 (선택)
- OpenAI 키를 연결할가? — 지금은 **불필요**(Gemini 무료로 시작). Gemini 품질 확인 후 아쉬우면
  `export OPENAI_API_KEY=...`만 주면 GPT 경로 추가. 스킨 대량 생산 시점에는 Recraft가 더 적합.
