# 튜토리얼 제작 계획 (2026-07-15 초안)

> 방식 선택은 대시보드 **🗳️ 선택 탭 6번 문항**에서. 선택되면 이 문서의 해당 안을 상세 설계로 확장해 구현한다.

## 목표
- 첫 실행 사용자가 **3분 안에** 장전→빵야, 방어의 삼각관계를 몸으로 익힌다.
- 끝나면 자연스럽게 "컴퓨터와 대결" 또는 "친구와 방 만들기"로 이어진다.
- 완료 보상(예: 300코인)으로 이탈 방지 + 상점 첫 해금 동기 부여.

## 공통 원칙
- 게임 로직 0줄 — 튜토리얼은 표시/입력 가이드 레이어로만 구현.
- 스킵 가능(우상단 '건너뛰기'), 완료 여부는 Meta에 저장해 1회만 노출.
- 문구는 정식 서비스 톤(#11 문구 전면 점검과 같은 라운드에서 통일).

## A안 · 가이드 봇전 (구현 3~4일)
실전 오프라인 화면 그대로, 보안관 코치 말풍선이 매 턴 지시.
1. 턴1: "장전을 눌러 총알을 채우세요" — 장전만 활성화.
2. 턴2: "봇이 쏠 겁니다. 방어로 막으세요" — 방어만 활성화(봇 강제 빵야).
3. 턴3: "이제 갚아줄 시간!" — 빵야만 활성화(명중 연출 풀 재생).
4. 턴4~: 자유 — 이기면 축하 + 보상. 지도록 두지 않음(봇 행동 시나리오 고정).
- 필요: 시나리오 봇(고정 행동 큐), 코치 말풍선 위젯, 버튼 잠금 상태.

## B안 · 코치마크 (구현 1일)
첫 실행 때 화면 위 반투명 레이어로 요소 하이라이트 + 말풍선 4~5장.
1. 액션 버튼 3개 → 삼각관계 설명 2. 좌석 카드(총알 수) 3. 내 카드 4. 시작하기.
- 필요: 오버레이 위젯 1개. 가장 저렴하지만 '해보며 배우기'는 아님.

## C안 · 만화 컷 + 봇전 (구현 2일)
4컷 만화(장전→빵야 관통, 방어가 막음, 총알 관리, 최후의 1인) 슬라이드 후 바로 봇전.
- 필요: 컷 일러스트 4장(사용자 이미지 스크립트로 생성 → 제가 규격화).

## 배치
- 진입점: 첫 실행 자동 + 상점 상단 '배우기' 카드 + 설정에서 다시 보기.
- 측정: 완료율/스킵률을 나중에 애널리틱스 붙일 때 1순위 이벤트로.
