# 리텐션·메타 시스템 계획 — 사례·방법론 리서치 기반

> **✅ 2026-07-12 사용자 선택 확정: A1·A2·A4·A5 + B1~B5 전부 진행. 광고 관련 요소는 전면 제외**
> (A3 광고 보상 탈락 · A1 복구권은 광고 시청 대신 **주 1회 무료 복구**로 — 광고 도입 시 광고 시청 방식으로 전환).
> 구현 순서: A(1~2주) → B1 → B2 → B5 → B4 → B3.

> 사례: Brawl Stars·Stumble Guys·Among Us·Archero·Clash Royale·Duolingo/Wordle 분석.
> 핵심 발견: 성공작은 전부 **일(미션) → 주(리그/랭킹) → 시즌(패스/신규 수집물)** 3중 케이던스를 갖고,
> 각 층이 다음 층의 재료(미션 완료가 패스XP를 줌)가 되게 연결한다.
> Among Us 반면교사: 진행 시스템이 없으면 "재밌는데 돌아올 이유가 없다" → 장기 리텐션 급락.
> 우리 자산: 출석 스트릭·일일미션·주간랭킹·캐릭터 수집·봇 40명·광고 슬롯 — **발명이 아니라 연결이 과제.**

## 방법론 7원칙 (적용 아이디어 포함)

1. **Hook 모델**(트리거→행동→가변보상→투자): 수집품·스트릭이 "투자" — 홈 화면에 상시 노출.
2. **약속 메커닉**: 0시 미션 리셋 + 주간 리셋 + 일요일 밤 시즌 정산을 이벤트화.
3. **손실회피·스트릭**: 7일+ 스트릭 유저 리텐션 2.4배(Duolingo). 스트릭을 불꽃 배지로 대문 노출 + 광고 시청 복구권.
4. **부여된 진행**: 패스 1티어 즉시 지급, 진행바 상시 노출, 마지막 3티어에 최고 보상.
5. **수집·완성 드라이브**: 도감 화면 — 미보유 실루엣 + 수집률 %.
6. **배틀패스 심리**: 무료 단일트랙만으로도 "버리기 싫다" 효과. IAP는 나중에 프리미엄 트랙만 얹기.
7. **작은 리그**: 전역 리더보드는 소규모에서 죽는다 — Duolingo식 **30명 버킷**은 유저 10명+봇으로도 성립(봇 러너 재활용).

## B2 스킨 — "노출 무대" 설계 (2026-07-12 사용자 질문: 인게임에서 안 보이는데 팔릴까?)

원칙: **스킨은 인게임 크기가 아니라 '노출되는 순간'이 판다.** 성공 게임들도 인게임 유닛은 작다 —
하스스톤(게임판 초상화 작음 → 선택·VS 연출·전용 대사가 무대), 브롤스타즈(인게임 콩알 → 로비 대형
스탠딩+승리 포즈), 어몽어스(최소 그래픽 → 회의 화면=전원이 서로 보는 순간), 클래시로얄(타워
스킨·이모트=상대에게 보이는 게 가치), LoL(유닛 작음 → 스플래시·로딩 화면이 실질 상품).

카우보이 적용 — 전면 개편 없이 무대 5개 추가(기존 로드맵과 결합, 좌석 카드 92~150px는 유지):
1. **결투(쇼다운) 컷인** — 타격감 2단계 'DRAW!' 예열 연출에 대결자 2인 초상 대형. 스킨의 메인 무대(전원 관람)
2. **승리 셀레브레이션 + 자랑하기 카드**에 승자 일러스트 대형 — 게임 밖으로도 노출
3. **로비/홈 내 캐릭터 대형 스탠딩** + 상점 구매 전 착용 미리보기
4. 좌석·킬 배너에 스킨 반영(기본 노출)
5. 전설급 스킨 = 전용 총성·승리 이펙트(크기 무관한 존재감)

구현 순서: 타격감 2단계에서 컷인·승리 무대의 "대형 초상 규격"을 먼저 만들고 → B2 스킨은 그 무대에 얹는다.
