# 치장(스킨) 업데이트 초안 v2 — TFT식 범용 장착형 (2026-07-15)

> **라운드2 노트 반영으로 전면 개정.** "캐릭터별 의상 일러스트"가 아니라 **모든 캐릭터가 공용으로 장착하는 치장템**(맵, 타격 연출, 처치 연출 등)으로 방향 전환. TFT(전략적 팀 전투)의 치장 구조를 참고했다. v1(캐릭터별 의상)은 폐기 — "각 캐릭터당 스킨을 뽑을 필요는 없어"(사용자 노트).

## 0. TFT 치장 구조 요약 (참고 원본)
- **전략가**(아바타 캐릭터) / **결투장 Arena**(보드 스킨) / **붐 Boom**(상대를 때릴 때 연출) / **피니셔**(탈락시킬 때 연출) / **감정표현 Emote**
- 재화: RP(유료) + **별 조각**(전략가 성장) — 치장 전용 재화가 게임 재화와 분리
- 등급 4단계(Standard/Legendary/Mythic/Prestige)로 희소성 축 부여

## 1. 카우보이 매핑 — 카테고리 후보 6종
| # | 카테고리 | TFT 대응 | 게임 내 노출 지점 | 제작 |
|---|---|---|---|---|
| 1 | **결투장 스킨** | Arena | 게임 화면 배경·모래·하늘 팔레트+장식(석양 협곡, 축제의 밤, 눈 오는 국경 등) | 코드 페인팅 — 이미지 생성 불필요 |
| 2 | **명중 이펙트** | Boom | 내 빵야가 명중하는 순간의 파티클·섬광 교체(다이너마이트, 카드 폭죽, 번개 등) | 기존 파티클 시스템 변형 |
| 3 | **처치 연출** | 피니셔 | 킬 슬로모 순간의 연출(까마귀 떼, 모자 헌정, 현상금 도장 등) | 킬 슬로모 훅 재사용 |
| 4 | **승리 셀레브레이션** | - | 승리 화면 콘페티·연출 변형(불꽃놀이, 금화 비 등) | 기존 셀레브레이션 변형 |
| 5 | 감정표현(말풍선) | Emote | 대기방·게임 중 이모트 휠 | 신규 UI 필요 — 2차 후보 |
| 6 | 좌석 프레임 | - | 좌석 카드 장식 테두리(티어 휘장과 별개 슬롯) | 티어 프레임 코드 재사용 — 2차 후보 |

**핵심 장점**: 1~4번은 전부 코드 드로잉/파티클 기반이라 **이미지 생성 파이프라인(사용자 대기) 없이 Claude가 직접 제작 가능**. 그리고 전부 표시 전용(게임 로직 0줄) → **kLogicVersion 증가 불필요**, 온라인은 좌석 claim에 표시 필드만 얹는다.

## 2. 새 재화 설계 (라운드2 노트: "다른 재화의 종류를 만드는 게 좋을 것 같아")
코인(캐릭터·게임플레이)과 분리된 **치장 전용 재화**를 신설. 라운드3 후보 3안:

| 안 | 이름(가칭) | 성격 | 획득 |
|---|---|---|---|
| A | **황금 별** ⭐ | 프레스티지형 — 코인으로 못 사고 플레이의 증표 | 시즌패스 티어(주 ~5개) + 주간 미션 올클리어(+2) + 트로피 마일스톤 + 이벤트 코드 |
| B | **은화** 🪙 | 교환형 — 코인 싱크 겸함(r2 가격 C안 12,000의 싱크 목적 계승) | A의 획득처 + **코인 2,000 → 은화 1 교환** 가능 |
| C | **보안관 배지** | 실력형 — 잘하는 사람의 과시 | 온라인 승리(+1)·3연승 보너스에서만 |

가격 축(별 기준 예시): 좌석 프레임 6 · 명중 이펙트 8 · 셀레브레이션 10 · 처치 연출 12 · 결투장 스킨 20. 시즌패스 완주(~4주) ≈ 별 20~25개 → "한 시즌 열심히 = 결투장 1개" 페이스.

## 3. 데이터 모델 (0.5일)
- `lib/meta/cosmetics.dart` — `CosmeticDef(id, type, name, desc, cost, source)` / type enum: arena·hitFx·killFx·winFx(+emote·frame 예약)
- Meta: `ownedCosmetics` Set<String> + `equippedCosmetics` Map<type,id> + 재화 잔액 int — SharedPreferences+클라우드 머지(기존 unlocked 패턴)
- **온라인 동기화**: 좌석 claim에 `fx` 필드(장착 명중/처치 id) — 표시 전용, 구버전은 무시 → 로직버전 그대로
- **결투장 표시 규칙**: TFT처럼 "내 화면엔 내 결투장" — 공유 상태 아님, 동기화 자체가 불필요

## 4. UI 노출 (1일)
1. **상점에 치장 세그먼트** 추가(캐릭터 캐러셀과 나란히) — 카드에서 미리보기+구매+장착 토글
2. **보상 탭/시즌패스**에 별 지급 티어 노출(코인 티어 일부를 별로 치환)
3. 명중/처치 이펙트는 상점 카드에서 **탭하면 데모 재생**(파티클 미리보기)

## 5. 단계별 일정 (총 ~3일, 이미지 대기 없음)
1. 재화+데이터모델+상점 치장 세그먼트(치장 0개여도 동작) — 1일
2. 1차 카테고리 2종 × 아이템 3~4종 제작(코드 페인팅) — 1.5일
3. 온라인 fx 필드+테스트/캡처 보고 — 0.5일
4. 시즌패스 P2(8/3~)에 별 지급·한정 치장 연결 — 0.5일
