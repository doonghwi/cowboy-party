# 스킨 업데이트 초안 (2026-07-15)

> SKIN_PLAN.md("무대 먼저, 스킨은 그다음")의 후속 — 무대가 거의 갖춰졌으니(승리 셀레브레이션·DRAW 컷인·**상점 캐러셀 대형 일러스트**·캐릭터 페이저) 이제 실제 업데이트의 구현 초안입니다. 검토 후 "진행" 한마디면 1단계부터 시작합니다.

## 한 줄 요약
**캐릭터당 의상 스킨**을 인게임 획득 전용(패스·트로피·골드)으로 추가한다. 그림은 초상 1장 교체 방식이라 게임 로직 0줄, 표시 파일 4곳만 바뀐다.

## 1. 데이터 모델 (Claude, 0.5일)
- 스킨 정의: `lib/game/skins.dart` — `SkinDef(id, charId, name, quote?, source, cost)`
  - id 규칙: `<char>_<theme>` 예) `prepper_highnoon`
  - source: `pass`(시즌 한정) / `trophy`(트로피 로드) / `shop`(골드) / `event`(선물코드)
- 보유/장착: Meta에 `skins`(Set<String>) + `equippedSkin`(Map<charId, skinId>) — SharedPreferences + 클라우드 머지(기존 unlocked 패턴 그대로)
- **온라인 동기화**: 좌석 claim에 `skin` 필드 1개 추가(표시 전용 — 게임 로직·리플레이 무관이라 **kLogicVersion 증가 불필요**). 구버전 클라이언트는 필드를 무시하므로 안전.

## 2. 에셋 규격·파이프라인 (사용자 생성 + Claude 가공)
- 파일: `assets/characters/skins/<skinId>.png` — 기존 초상과 동일 규격(정사각, 흉상, 흰 배경 제거본)
- 생성: SKIN_PLAN.md의 프롬프트 템플릿(참조 이미지 첨부 필수) → 캐릭터당 후보 4장
- 승인: **사운드 보드와 동일하게 스킨 보드**(html)로 O/X — 승인분만 rembg·512 규격화해 반영
- 1차 물량 제안: 전 캐릭터 말고 **인기 3캐릭터 × 1스킨**(스나이퍼·의사·쌍권총)으로 시작 — 파이프라인 검증 후 확대

## 3. UI 노출 지점 (Claude, 1~1.5일)
1. **상점 캐러셀**(이번에 만든 A안): 카드 하단에 스킨 썸네일 줄 추가 — 탭하면 히어로 일러스트가 그 스킨으로 스왑 + 장착/획득처 표시
2. **좌석 카드/페이저/셀레브레이션**: `CharacterPortrait(id:)`가 장착 스킨 id를 받도록 한 줄 확장(폴백=기본 그림)
3. **도감**: 캐릭터 카드에 스킨 슬롯 점(●○) — 수집률 드라이브
4. 로비 컴포넌트 규칙 준수: 스킨 UI도 배경 채운 카드로

## 4. 획득 경로·가격 (밸런스 초안 — 결정 필요)
| 경로 | 스킨 | 비고 |
|---|---|---|
| 시즌 패스 P2(8/3~) 30티어 | 한정 1종 | 피날레 보상, 시즌 지나면 미획득 |
