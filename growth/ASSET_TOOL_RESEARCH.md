# 게임 에셋 AI 생성 툴 조사 (2026-07-16)

> 배경: 라운드4 명중 이펙트 시안 퀄리티 지적 — 지금은 전부 코드 드로잉(선·도형)이라 한계. API로 연결해 디자이너급 에셋을 뽑을 툴을 비교했다. 결정은 🗳️ 선택 탭 라운드4 추가 문항.

| 용도 | 형태 | 비고 |
|---|---|---|
| ① 명중/처치 이펙트 | **움직이는 연출** — 플립북 스프라이트시트(연속 프레임) 또는 파티클용 낱장 텍스처(불꽃·연기·별) | 지금 지적받은 부분 |

| ③ 캐릭터 스킨·일러스트 | 기존 15인 일러스트와 **스타일 일관** | 결투장 스킨 배경도 |

| 툴 | 강점 | API·가격 | 상업 이용 | 우리 용도 적합 |
|---|---|---|---|---|
| **Scenario** (게임 특화) | **내 그림으로 스타일 학습** → 일관된 에셋. 이미지·영상·GIF·오디오까지. Unity 플러그인, API-first | 무료 50크레딧/일 체험 → Pro $15~45/월 | Creator($50/월) 이상에서 완전 상업권 — **주의: 하위 플랜은 제한** | ③ 최강, ①도 프레임 생성 가능 |

| **VFX 특화 무료** (Quick Sprites/spritesheets.ai/Spritefy) | 폭발·번개·마법 등 **VFX 플립북 전문**, 24~96px, 수십 초 생성 | 무료~저가 웹툴(정식 API는 제한적) | 툴별 확인 필요 | ① 빠른 실험용 |
| Gemini API (보유 키) | 범용, 이미 연결됨 | 결제 연결 시 ~$0.04/장 | OK | 범용 백업 |
| EmberGen | 실사급 폭발 시뮬→플립북 | $23~/월, 데스크톱 | OK | 우리 그림체엔 과함 |

## 이펙트(①)를 "움직이게" 만드는 두 경로
1. **플립북 방식**: AI로 8~16프레임 스프라이트시트 생성 → 앱에서 프레임 순차 재생(Flutter에서 간단). 디자이너가 그린 듯한 풍부한 연출. 프레임 간 일관성이 관건 — Scenario/VFX 특화 툴이 유리.
2. **하이브리드(추천)**: AI로 **낱장 텍스처**(불꽃 혀·연기 뭉치·별·카드 등 3~5장)만 뽑고, 움직임은 지금 파티클 엔진이 담당. 프레임 일관성 문제가 없고 용량도 작음. Leonardo 투명 PNG가 딱 맞음.

## 추천안
- **1순위: Scenario 무료 체험(50크레딧/일)으로 시작** — 명중 이펙트 텍스처+플립북, 카우보이 그림체 학습까지 시험 → 결과를 자료실 보고서로 검사받고 유료($15~) 전환 결정.
- **가성비 대안: Leonardo $9/월** — 투명 PNG 텍스처 중심 하이브리드.
- **병행 소액: Recraft $10 선불** — 휘장·황금 별·치장 아이콘 등 벡터류 전용(이펙트와 무관하게 가치 있음).
- 어떤 툴이든 산출물은 rembg·규격화 후 **선택 탭/자료실에서 검사** 후 반영(고정 규칙).

## 연결 시 필요한 것(사용자)
- 가입 + API 키 발급 → `~/.zshrc`에 저장(예: `SCENARIO_API_KEY=...`). 이후 생성→후처리→시안 게시는 Claude가 자동.
